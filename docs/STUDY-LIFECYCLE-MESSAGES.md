# Fleuron Study Lifecycle Messages and Action Guidance

This document catalogs reachable warning, error, and recovery states across Fleuron study lifecycle workflows (opening, creating, joining, setting up, detaching, leaving, deleting, and restoring studies).

Every condition specifies its originating source, trigger condition, former legacy copy, user-facing replacement copy, available next actions, and automated verification tests.

Platform-specific terms (such as file manager and trash) resolve dynamically at runtime via `fileManagerName` and `trashName()` (`src/lib/platform.ts`). Technical diagnostics and credentials are strictly scrubbed by `scrubDiagnostics` before display or logging.
